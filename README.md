Introduction
This repository is curated and maintained by Zerodays Company Inc. It provides a comprehensive index of free and open-source (FOSS) music applications serving as open alternatives to mainstream streaming services like Spotify and YouTube Music. The listed applications range from cloud and API-driven streaming clients to lightweight offline media players.
